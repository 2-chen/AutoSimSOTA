# 数据是资产，不是实验临时文件

先区别原始轨迹、处理后训练视图、可再生缓存、展示媒体和诊断失败记录。它们可能包含相同画面，但保留与复用条件不同。当前 `data_versions` 是单 run 的身份/loader 登记，不是跨 run 数据仓库；当前存储回收接口拒绝数据生产者，不得绕过它删除数据。

登记来源、真实生产回执、父版本和转换配方时，按需读 [原生数据合同](../curating-simulation-datasets/references/native-data-contract.md)。新版卡支持这些证据并在采用前复核父数据；没有 profile 的旧卡保持 unknown。元数据卡不是备份，可逆配方也不保证仿真采集能完全重放。

## 保留能追溯的来源

检查生产者源码/revision、任务和训练范围、真实 attempt、动作提供者/权重身份、观测与控制语义、模拟器/资产配置，以及来源许可和资源访问范围。计数未知就保留未知，不从文件数量猜 episode。重启或删除 run 前先识别数据所在位置和被哪些测量引用；单独记录 hash、seed 或文件名都不是可恢复的备份。

raw 不原地转换、重编号、改标签或重算归一化。输出新位置并记录 parent 身份、转换代码/参数、选择的完整轨迹和统计来源；处理后的版本与源版本分开登记。以元数据/引用复用兼容数据，不能默认完整复制；内容相同不等于任务、控制器和划分兼容。近重复分数只帮助选择，不授予物理删除权限。

采集中的未完成文件与已封存可读数据分开，检查原生 writer 的关闭/finalize 和恢复语义。失败 attempt 可能已有可用完整 episode，需逐项验证；不能默认为成功全集，也不因外层超时直接丢弃它们。断点续采必须去重已提交身份，不能仅按目录最新编号续写。当前工具不能实现的发布/复用操作报告为能力缺口，不虚构数据管理 API。

## 磁盘不足时先减少新增

估计 raw、多相机视频、转换副本、解码缓存、训练快照与预览的峰值；实测大小与估计分开。优先缩小下一批、减少可选展示产物、请求合法存储控制或暂停新生产。停止位置和 writer 恢复由原生语义决定，不承诺随意中断不会丢数据。

不可再生 raw、已计分/在用的数据与恢复证据优先保留。缓存也只有在源字节、重建代码/配置和成本已知时才可称为可再生；没有原生回放验证，不把仿真 seed 当作全部 raw 的替代。LLM 可以提议数据迁移、归档或缓存清理，但执行须另有明确目标、权限和受控事务。不能拿已有 checkpoint 清理授权覆盖数据。

单盘副本或 COW/硬链接不是独立备份。归档需核对目的介质、完整身份和可恢复读取；远程上传/下载、许可与费用需要对应权限，不因配置了模型 API 就把 raw 上传。共享缓存回收须核对所有使用者/历史引用；未知引用、活动 writer、未完成事务不自动回收。

## 给主 Agent 的短交付

提供来源和内容身份、版本/parent 关系、已核验消费与兼容限制、存储测量/估计、保护项、下一步及证据链接。主 Agent 据此决定复用、试采或请求明确维护动作；RUN.md 用中文说明数量变化、保管位置、备份核验与待补缺口，不把仅登记/归档写成增分。

需要内容寻址、分片/血缘、事务、保管层级与接口边界的设计依据时，按需读 [数据中心研究与资产管理调研](../curating-simulation-datasets/references/data-centric-research-20261006.md)。该设计多数仍是规划，不是现有可执行接口。
