# 具身仿真增分方法调研

核查日期：2026-09-29。用途：供 Agent 按需选取可测试的假设，不是排行榜或保证 SOTA 的配方。本轮阅读原始论文摘要、相关章节/表格及作者官方项目/文档；没有复现这些方法，也未全面审计其实现代码。公开网页会更新，执行时必须将本地 commit、资源版本与阅读版本对齐。

## 1. 对当前目标最有用的结论

在每仓库最多 24 GPU 小时、资源可复现的机械臂任务范围内，更值得优先验证的通常是：接口正确性和有效训练、可消费的新数据、低成本控制/采样改进。该顺序是结合本系统失败记录与资源约束的工程判断，不是论文对这些方向做过统一预算排名。

“修好了加载路径”是工程恢复；“比同机基线高”是本地增分；“超过同协议最新最优”还需要完整可比性、独立确认和当时公开结果核查。不能把任一阶段替代后者，也不能把增加论文/技能数量当作系统已会研究。

## 2. 原始证据与可迁移结论

| 来源与核查位置 | 来源支持什么 | 不支持什么 / 如何落地 |
| --- | --- | --- |
| [robomimic，2021，v2 摘要](https://arxiv.org/abs/2108.03298v2) | 演示质量、算法设计与训练停止点影响机器人学习；训练和评测目标有差异 | 不保证最低 loss 的 checkpoint 最好。先核对原生配置、有效训练和开发 rollout |
| [MimicGen，2023，官方方法与数据展示](https://mimicgen.github.io/) | 少量源演示经适配可扩展到新 reset、物体等条件，再用于策略学习 | 不等于所有仓库天然有可用生成器；先查源演示、专家/分段信息、格式和真实 loader |
| [Data Scaling Laws，v4，摘要](https://arxiv.org/abs/2410.18647v4) | 真实机器人实验支持关注环境/物体多样性及重复数量的边际收益 | 不是仿真通用样本配额；把覆盖与重复作为同成本候选比较 |
| [RoboCasa365，2026，v1 §4.4 / 表4](https://arxiv.org/html/2603.04356v1) | 在其预训练/目标任务协议中，多样性和数据混合影响迁移；10% 目标数据下 Human300 平均 40.0%，加 MG60 后 35.9% | 不证明所有合成数据有害，也不能将同时变化的因素全归因质量；保留原数据对照 |
| [DataMIL，v2，摘要](https://arxiv.org/abs/2505.09603v2) | 用与下游策略表现相关的数据选择，替代仅靠外观/语义相似度挑数据 | 本轮未审计选择器成本或复现；小预算先尝试可解释分组/权重，再考虑复杂选择器 |
| [ACT，2023，论文摘要](https://arxiv.org/abs/2304.13705v1)、[官方项目](https://tonyzhaozh.github.io/aloha/) | 动作序列建模是针对累积误差/精细操控的有效研究方向 | 原始主要结果为真实机器人，不保证当前仿真最优；参数和权重结构需匹配 |
| [Diffusion Policy，RSS 2023 / IJRR 2024，官方方法](https://diffusion-policy.cs.columbia.edu/) | 动作分布建模与滚动时域控制结合，在多任务评测中得到改善 | 不保证扩散总优于确定性策略；需验证动作表达、采样成本和控制延迟 |
| [DP3，RSS 2024，官方方法与实验概览](https://3d-diffusion-policy.github.io/) | 稀疏点云表征结合扩散策略，在多种仿真任务中评测 | 输入模态可能改变比较协议；深度/标定/坐标系不齐时不能强上 3D |
| [OpenVLA-OFT，2025，v2](https://arxiv.org/html/2502.19645v2) | 并行动作预测、chunking 和连续动作学习可改善其 VLA 的速度/成功表现 | 不是“越大越好”，也不意味着当前最优。需要匹配 backbone、动作头与统计量 |
| [OpenVLA-OFT 官方 FAQ](https://openvla-oft.github.io/) | 官方报告训练用 8 张 80GB A100/H100，1–2 天；LoRA 仍有可观资源要求 | 不可换算为单张 5090 的承诺；先测显存和吞吐，再决定预算内微调或采用小模型 |
| [DAgger，2011，v3 摘要](https://arxiv.org/abs/1011.0686v3) | 针对策略诱导分布的迭代数据聚合处理序列预测分布偏移 | 要有可用专家标签；失败动作本身不是正确监督，标准 reset 专家不一定能接管中间状态 |
| [DPPO，2024，官方方法](https://diffusion-ppo.github.io/) | 针对扩散策略的在线策略梯度微调，可改善其任务表现与恢复行为 | 不证明任意模型可直接套 PPO 或稀疏奖励从零容易学；先验证原生训练接口和吞吐 |
| [ASHA，原始论文](https://arxiv.org/abs/1810.05934) | 多保真资源分配为筛选假设提供方法参考 | 不保证早期 loss 能预测后期机器人成功率；正确核算晋升与重启成本 |

以上仅摘要或已核查章节范围内的转述，没有把论文单点效果写成当前任务的预期增分。应用到本系统的接口检查、最小实验和停止条件是方法设计，需本次运行验证。

## 3. 仿真资源接口的两个具体例子

- [RoboTwin 官方采集文档](https://robotwin-platform.github.io/doc/usage/collect-data.html) 描述任务脚本与规划器结合的自动采集、seed 搜索/回放和预采数据下载。当前在线页面还描述 XPolicyLab 格式；**本地旧版本不一定相同**。用它作入口线索，不把该页的命令/格式覆盖到任意 checkout。
- [ManiSkill 官方运动规划文档](https://maniskill.readthedocs.io/en/latest/user_guide/data_collection/motionplanning.html) 提供部分 Panda 任务的规划演示生成接口，非所有任务都有专家。[演示学习 setup](https://maniskill.readthedocs.io/en/latest/user_guide/learning_from_demos/setup.html) 说明压缩演示可能不含观测，需要按规定重放。这解释了“有数据文件”与“训练能消费”不是一回事。
- [ManiSkill 原生 RL baselines](https://maniskill.readthedocs.io/en/latest/user_guide/reinforcement_learning/baselines.html) 展示基于在线交互的不同工作流；不能要求所有仓库先完成独立演示采集再开始学习。

这些是不同工作流的例子，不进入核心执行器的仓库名条件分支；由 Agent 阅读当前原生实现推导连接。

## 4. 成本、前提与最小对照

下表是本系统建议，不是额外权限或硬编码顺序。低/中/高表示相对改造与验证成本，不是固定小时数。

| 方向 | 成本/先决条件 | 最小有意义的对照 | 推迟或停止信号 |
| --- | --- | --- | --- |
| 接口/身份/训练核验 | 低；源码、样本、原生推理 | 修复后重测原 baseline，再比较 candidate | 源码/数据/权重缺口未解决，不能开始归因 |
| 分块/反馈/采样 | 低到中；策略实际支持 | 同策略开发初态，小范围合法设置；结构变化须重训 | 延迟/动作退化或权重不兼容 |
| 训练量/学习率/EMA 等 | 中；有效更新和可恢复状态 | 同初始化、数据、主要计算口径 | 预算不足以产生学习信号或无效更新 |
| 原生采集与覆盖 | 中；协议允许、专家可用、loader 接通 | 原数据继续训练 vs 新增数据；记录全部采集成本 | 低产出、数据未消费、开发收益不明确 |
| 质量/权重 | 中；有来源与质量区分 | 原样混合 vs 单一干预，控制 sampler 混杂 | 过滤损失难例覆盖或遗忘 |
| 视觉/历史 | 中；合法输入与兼容训练 | 一种增强/历史改变 vs 原配置 | 不合法观测、无可测改善或成本过大 |
| 新策略/预训练/3D | 中到高；完整资源与兼容协议 | 可运行原生基线保留，披露额外数据和预训练 | 显存、标定、许可、资源或总预算不足 |
| 专家纠错/在线 RL | 中到高；中间状态专家或原生训练反馈 | 同成本普通数据/原策略参照 | 不可标注、奖励无信号、吞吐或接口不成立 |

成功率高不意味着没有研究空间，可考虑协议允许的更稳健行为或推理成本，但不能私自换正式目标。剩余预算很少时可只保留明确证据、确认现有最佳，不强求一轮昂贵新算法。

## 5. 所有方法共同的有效性条件

1. 不用正式留出反馈选 idea、数据、超参数或 checkpoint；开发与确认分开。
2. 不改变冻结的任务、初态分布、控制/物理、成功条件和评分聚合。
3. 核对训练产物→实际加载→rollout→指标身份，而非只检查路径/日志数字。
4. 原数据/基线保留，累计采集、训练、筛选、失败和复评成本可追溯。
5. 报告原始计数、配对关系与不确定性；单臂区间重叠不是差异检验。
6. RUN.md 用中文解释研究问题、结果与下一步，展示有来源的行为视频/数据图；好看的片段不代替统计。
7. 知识与执行能力分开：写入 skill 不会自动补齐采集长作业、转换缓存或候选领养接口；真实接通仍需验收。
