日期：2026-09-29。范围：原有 28 个内置技能、manifest 和加载/显式选读合同；不重写旧 run，不删除历史 ID，不复核全部历史实验或自动蒸馏记忆。

## 整理结果

新增 7 项，共 35 项：研究方向路由、策略输入动作对齐、有效训练与身份、动作分块与反馈、观测与记忆、预训练适配、专家纠错/在线学习。以中文导航分类，正文按具体问题、前提、验证和停止条件编写；调研放 references 按需读，不整库注入。

原条目中数据/统计/接入的一般方法重新审视并改写。保留相邻技能的不同问题，避免把“数据更多”“数据更好”“采样更多”混成一种干预。RoboSyn 专属历史材料保留并降低未复核结论的使用强度；不擅自删除原始数字或把历史能力当当前能力。

## 关键纠正

| 原来的风险 | 处理 |
| --- | --- |
| benchmark-shapes 把特定成功谓词、两视角、horizon 截断写成 universal | 全部改为需从源码/运行查证的维度 |
| 部分数据技能把局部增分、无收益或 p 值写成普遍因果规律 | 通用正文去掉未经复核的本地定量断言；保留条件性方法与必要原始来源 |
| “更多数据一定无效”“混合质量 BC 不可用”“小集合一定要 0.5” | 改为同成本、实际曝光与开发验证的假设 |
| 分布重叠就认为更多样本无用 | 区分样本不足、噪声、饱和/错误指标和效应大小 |
| 单臂区间重叠等于不显著、共享 seed 消除全部方差 | 改为差值/配对/独立单位分析，并说明反复选优风险 |
| 仿真内部状态作评分一概无效 | 区分合法 evaluator 与禁止泄入 policy 的特权信息 |
| “发布 checkpoint 不是 baseline”“必须同时匹配 steps 和计算量” | 区分合法基线、方法归因与计算效率问题 |
| ASHA 示例把十个 5 epoch、两次晋升、一次确认算成 50 epoch | 明确可恢复总量 110；重启则 140，且真实成本还需吞吐换算 |
| loss 可分开算法就视作可筛选代理 | 必须检验对后期开发目标的预测性，跨 loss 定义不可直接比 |
| README 不会错、缺数据一定在邻居目录、HDF5 必须零 worker | 改为当前版本/消费者查证、授权资源范围、条件性故障修复 |
| 文档没资源链接就停止，或策略切换忽略权重配套 | 补官方搜索、资源来源/许可、兼容性、从头训练成本与明确边界 |
| 崩溃等于资源上限、任何相同配置重试都无效 | 先封存/读取稳定证据，允许有根据的瞬时重试与诊断重放 |

旧技能中未在本次核实的若干扩展论文编号与精确百分比已从通用指导移除；这不是判定论文不存在或结果错误，而是不再用未核实细节支持当前强结论。保留的文献转述见 [调研及核查位置](literature-review.md)。

## 维护合同与边界

- manifest 发布为 1.1.0，旧 ID 和路径不变；选择回执仍记录版本与正文哈希。
- 现有自定义 scope/confidence/evidence frontmatter 保留，由项目 discovery 验证；7 个新技能使用 name/description 标准 frontmatter，证据边界在正文，可另用 skill-creator quick_validate。
- skill-creator 的组织方法用于缩短指引、按需引用、写清触发与验证；没有将项目内技能安装为用户全局 Codex 技能。
- 短目录发现/范围过滤/明确选读属于软件合同；真实 LLM 是否选对技能、是否采用并得到增分仍需新 run 验收。
- references 的本地链接已校验，但当前显式技能接口不递归返回参考文件，目标仓库沙箱也不保证挂载宿主技能目录。本轮正文自包含关键方法；参考资料属于按需可读资源，不声称新增了运行时参考文档工具。
- 没有新增模型调用、GPU 训练或仿真；没有实测任何新增方法达到 SOTA。技能也不修复执行图的全部数据转换、缓存或长期候选事务缺口。
- 后续验证优先观察真实 run 的选择理由、原生采集到 loader、baseline/candidate 身份、失败复验和中文 RUN.md。若失败，修具体缺失的信息/执行边，而非再添仓库名规则。
