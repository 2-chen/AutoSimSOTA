# AutoSimSOTA: Autonomous Research over Native Simulation Repositories

论文草稿骨架，已有 24%→32% 的自主部署优化开发案例；正式数据方法对照待执行。不声称达到 SOTA。

执行拆分（2026-10-15）：系统主实验验证原生接入、自主择路、持续指标优化及完整成本；数据专项以random/rule/agent验证获取，再以Qt矩阵验证筛选增量。数据矩阵仍为draft，不代表系统主表；尚无正式系统比较结果。

## 摘要

问题：能否让AutoResearch从原生仿真仓库形成并演化可执行研究路线，而不只优化人工准备好的模板？方法：Main按当前证据在获取诊断信息、获取训练经验、修改学习／部署方法之间择路；原生连接、有限资源、恢复与独立计分支撑持续优化。数据是重要领域分支。主实验比较通用工作流和autoresearch-robotics，数据专项解释定向获取收益；正式结果和具体数值待填，不写预期正结论。

## 1. Introduction

## 2. Related Work

AutoSOTA / 自动研究工程、autoresearch-robotics的算法重写／RL经验采集／视觉研究；MimicGen与专家生成、DART／DAgger纠正、DataMIL选择、RESample恢复。承认重叠，分别检验仓库接入、自主择路与数据机制，不声称首个仿真研究循环。

## 3. Method

系统主方法：能力／前提重建、动态干预选择、短研究循环、按需技能与决策记忆、实际产物与计分、恢复和资源。数据子方法：条件与专家、Q0／Qt、数量／混合／真实batch。可选视觉需真工具支持；给出决策当时证据，不把维护干预包装成自主科研。

## 4. Experiments

系统主表：不同能力任务、固定配方／通用工作流／完整系统，匹配总资源、至少3次独立Agent研究，原生最终指标、完成率与全成本；共同模板与仓库接入分开。数据专项：等接受量／等成本、随机／规则／Agent及Qt。研究重复、训练seed与episode分层，真实迁移和全部失败纳入。

开发案例单独呈现：RoboSyn click_bell 的本地 ACT 基线 24/100，同一权重下由 Agent 将动作执行长度从 8 调到 16 后测得 32/100。已发布权重另有本地 55/100 测量，协议可比性仍须审核。独立确认因源码身份前置检查未执行；无多种子、配对初态或显著性结论。整轮有人类框架修复和重启，新增采集输出未被候选训练消费，因此案例不是正式自主性结果、SOTA 或 FDAS 有效性对照。详见 [案例证据](DEVELOPMENT_CASE_ROBOSYN.md)。

## 5. Analysis and Limitations

采集收益是否来自新增数量还是目标相关性；重复/拒绝与实际曝光；目标难度及专家可恢复性；失败例子；不支持自动专家的仓库；数据许可与资源依赖；规模和算力限制；LLM 推理成本。
