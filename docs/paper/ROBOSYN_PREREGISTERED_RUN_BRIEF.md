# 新预声明 RoboSyn 数据研究运行

此文件在新 run 初始化前写入。用户于2026-10-11授权另开复用现有环境/资源的研究run，保留旧试点及全部费用、预留和GPU历史。不是批准旧试点追溯成为论文trial，也不是预先宣布正式主表有效。

## 研究与评测边界

沿用PILOT_BRIEF的失败驱动数据获取/筛选目标。先完成合法训练数据→原生学习→实际加载→rollout→计分，再做失败定向与同专家随机获取的直接比较。Data决定合法获取和筛选，Resource安排总预算内局部窗口，Main协调；不由操作者指定训练步数、目标profile、接受数量或候选模型。

任何evaluate命令验收、参考评测或后台评测前，先调查原生评测输入的真实初始化路由，调用configure_confirmation_protocol建立独立条件。不能只换seed标签而不追踪实际随机源/初态。必要校准和不改变任务/成功判据的见证接线在正式冻结前完成。先建立collect/转换/训练入口与数据可控轴，再冻结正式协议；不要在接口还缺失时抢跑评测。已观察到旧试点评测的任务不是完全未知留出任务；未来任务/仓库留出必须另外预声明。

开发失败可用于决定训练域的数据策略；独立确认只在研究结束时运行，不向Data透露确认结果。campaign与recipe必须先于数据干预登记；旧采集数据不能改标签成为本轮targeted/random干预。最终多seed/公平性/逐arm成本与匿名审核仍是论文准入门槛。
